# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

The Universal AI Agent Skills maintainers take security seriously. If you discover a vulnerability or security flaw in any skill template, script, or configuration:

1. **Do not create a public GitHub issue.**
2. Please report the issue privately by emailing `security@autonomous-skills.org` or creating a private advisory on GitHub.
3. Provide a detailed summary, steps to reproduce, and affected skill path.

We will acknowledge receipt within 48 hours and work with you to release a remediation patch promptly.
